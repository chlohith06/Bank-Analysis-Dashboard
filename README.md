# 🏦 End-to-End Bank Analysis Dashboard

## 📌 Project Overview

This project is an end-to-end Banking Data Analytics solution developed using **Python, MySQL, Jupyter Notebook, Google Colab, and Power BI**. The project focuses on analyzing customer loan and deposit data to generate meaningful business insights through interactive dashboards.

The workflow includes data cleaning, exploratory data analysis (EDA), SQL database management, data transformation, and dashboard development.
